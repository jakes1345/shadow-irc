    🚀 SHADOW-IRC Cosmic Onboarding & Operator Guide

    🌌 1. Zero-Data Privacy Architecture

    SHADOW-IRC is a 100% free, open-source cross-platform suite with zero email, zero phone number, and zero personal data collection.

    All authentication happens in-protocol via built-in Services (`NickServ`, `ChanServ`). Your IP address is automatically cloaked as user@cosmos/shadow/x-hash across all channels.

    Quick Tip: Use the quick buttons in the top header bar or type commands directly into the prompt box at the bottom.

    🛡️ 2. NickServ: Device-Key Registration

    Register your nickname to this device. Your browser creates a private key it can sign with but never reveal; the server stores only the public half — no password, no email, no timestamps.

    /ns REGISTERKEY (the Register button does this for you)

    Reconnecting identifies you automatically. To add a second device, click Register there and confirm once with your password, or from an identified device:

    /ns ADDKEY <pubkey>  ·  /ns LISTKEYS  ·  /ns DELKEY <fingerprint>

    Password fallback for native IRC clients: /ns REGISTER <password> and /ns IDENTIFY <password>.

    👑 3. ChanServ: Channel Ownership & Operator Privileges

    Register a channel to become its permanent Founder with @Operator rights.

    /cs REGISTER #channel [description]

    Grant Operator status to crew members:

    /cs OP #channel <nickname>

    ⚡ 4. Server Operator (/oper) Authorization

    Operator status belongs to the Network Master account. Identify as Shadow (device key or password) and it is granted automatically — there is no shared oper password.

    /oper

    Broadcast network notices to all connected nodes:

    /wallops <message>

    🔒 5. E2EE Encryption & ZNC 24/7 Bouncer

    Set a local client encryption key for channel privacy:

    /encrypt cosmic_secret_key

    Enable 24/7 Bouncer persistence so unread messages queue while offline:

    /bouncer enable
